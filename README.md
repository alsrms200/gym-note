# 쇠질 노트

헬스장에서 혼자 쓰는 운동 기록 웹앱. 설치·서버·로그인 없이 브라우저에서 바로 동작하고, 기록은 기기 안(localStorage)에만 저장된다.

## 기능

- **오늘**: 이번 주 출석 체크, 주간 목표 진행, 다음 순서의 추천 루틴, 코치 메모(목표 페이스, 연속 운동 시 휴식 권고, 빠진 부위, 증량 시점)
- **루틴**: 밀기/당기기/하체/전신 기본 루틴 제공, 직접 만들기·수정(운동 56종 + 직접 추가, 세트·횟수·시작 중량·휴식 시간)
- **운동 진행**: 총 운동 시간, 세트 완료 체크 시 휴식 타이머 자동 시작(±10초, 건너뛰기, 종료 알림음·진동), 지난 기록 표시와 자동 입력, 증량 제안, 화면 꺼짐 방지. 새로고침해도 진행 상태 유지
- **기록**: 월 달력 체크, 운동별 상세, 신기록 표시
- **통계**: 최근 7일 부위별 세트 수, 8주 운동 횟수, 종목별 추정 1RM 추이
- **설정**: 주간 목표, 기본 휴식, 알림, 백업 파일 내보내기/불러오기

## 실행

빌드 과정이 없다. 정적 파일을 그대로 올리면 된다.

```bash
npx serve .
```

GitHub Pages: 저장소 Settings → Pages → Branch `main` / root 선택. 휴대폰에서 주소를 연 뒤 "홈 화면에 추가"하면 앱처럼 쓸 수 있고 오프라인에서도 열린다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 진입점 |
| `app.js` | 상태, 화면, 타이머, 추천 로직 |
| `data.js` | 운동 목록, 기본 루틴 |
| `styles.css` | 스타일(라이트/다크 자동) |
| `sw.js`, `manifest.webmanifest`, `icon.svg` | 홈 화면 설치, 오프라인 |
